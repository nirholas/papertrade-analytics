Headline numbers

Time series

Crosshair for exact values. Hover a legend swatch to read what it plots. The protocol keeps hourly history, so ranges under an hour widen to the latest few buckets.

Markets

Mid prices are Hyperliquid candle closes. Long and short are the open notional the house is carrying.

PAPER economics

PAPER is minted to losing traders and staked to earn the protocol's fees. The mint rate falls along a fixed curve as the protocol grows.

Leaderboard insights

Top traders by windowed PnL, how they size and lever, and how concentrated open notional is. Wallets open in the explorer.

Built for people and for agents

One data layer, three ways in: the dashboard, a plain JSON API and a read-only MCP server.

  • Live protocol numbers

    TVL, margin, LP equity, volume, open positions and traders with 24h and 7d changes, always labelled when history is too short to claim a window.

  • Charts you can export

    Six time series with range, market and scale controls and per-chart CSV. Volume is split by market; cumulative counters are never passed off as flows.

  • Skew, caps and a simulator

    See which side the house is carrying, how close each market is to its cap, and what a win keeps at your leverage, computed with the SDK's own settlement math.

  • PAPER, explained

    Supply read on-chain with an indexer fallback, the mint-rate curve with today's position marked, and how much of the supply is staked.

  • Who is winning, and how

    A sortable leaderboard plus distributions of position size, leverage and concentration. Wallets open in the explorer.

  • Agent-ready

    A keyless MCP server with 8 read-only tools, OpenAPI 3.1, an A2A agent card, llms.txt and docs served as markdown. Nothing here can trade.

Connect your AI

One URL, no key, no sign-in: https://papertrade-analytics.pages.dev/mcp. Ask your assistant for the open interest skew, the PAPER mint rate or this week's top traders.

Run once in your terminal. Add --scope user to use it in every project.

claude mcp add --transport http papertrade-analytics https://papertrade-analytics.pages.dev/mcp

Settings, Connectors, Add custom connector, then paste the URL above. On an older desktop build, bridge it in claude_desktop_config.json:

{
  "mcpServers": {
    "papertrade-analytics": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://papertrade-analytics.pages.dev/mcp"]
    }
  }
}

One command, or add the same table to ~/.codex/config.toml.

codex mcp add papertrade-analytics --url https://papertrade-analytics.pages.dev/mcp
[mcp_servers.papertrade-analytics]
url = "https://papertrade-analytics.pages.dev/mcp"

Add to .cursor/mcp.json (project) or ~/.cursor/mcp.json (all projects).

{
  "mcpServers": {
    "papertrade-analytics": {
      "url": "https://papertrade-analytics.pages.dev/mcp"
    }
  }
}

Run once in your terminal.

gemini mcp add --transport http papertrade-analytics https://papertrade-analytics.pages.dev/mcp

Add to .vscode/mcp.json for Copilot agent mode.

{
  "servers": {
    "papertrade-analytics": {
      "type": "http",
      "url": "https://papertrade-analytics.pages.dev/mcp"
    }
  }
}

Settings, Apps, Advanced settings: turn on Developer mode, then Create app. Paste the URL below, choose No authentication, and enable the app from the plus menu in a new chat.

https://papertrade-analytics.pages.dev/mcp

Quickstart and JSON API

No key, CORS open, cached 30 seconds at the edge.

Ask the MCP server

Call a tool directly, no client needed.

curl -s https://papertrade-analytics.pages.dev/mcp \
  -H 'content-type: application/json' \
  -H 'accept: application/json, text/event-stream' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"get_protocol_snapshot","arguments":{}}}'
